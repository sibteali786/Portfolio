The Excel Problem

Asia Group runs construction projects across UAE, Oman, and Pakistan. Every project lived in its own Excel file — income, expenses, vendor balances, and receipts all tracked by hand. One formula mistake broke the entire sheet. Comparing profit across three projects meant opening three files and adding by hand. When an auditor asked for a receipt, it meant 30 minutes searching physical folders. There was no access control: anyone with the file could edit or delete anything, and nothing left an audit trail.

What Was Built

  • Auth & role-based access — OWNER (view-all, no accidental edits), ACCOUNTANT (data entry only, can't delete completed projects), REVIEWER (full audit + edit with complete change trail). CEO in Dubai sees the same live data as the accountant in Islamabad — no email attachments.
  • Project dashboard — all active projects on one screen with live P&L; per-project income/expense/net profit updated the moment a transaction saves; independent endpoints per section so one failure doesn't break the dashboard. CEO sees Plot 930 G-11/2 at PKR 29,550 profit vs Plot 45 F-10 at a loss in 10 seconds.
  • Transaction management — INCOME / EXPENSE / DUE with auto-generated reference codes (e.g. EXP-NIS-0001, INC-0003) on every entry; auto-calculated balances; receipt upload (PDF/image) attached directly; physical file reference (Fax No.) preserved.
  • Due settlement flow — full DUE → PARTIALLY_SETTLED → SETTLED lifecycle backed by a transaction_settlements join table linking each payment to the specific dues it covers. A settlement modal previews open balances and records batch payments in one step.
  • Vendor management — complete vendor profiles (CNIC, phone, bank); tracks contracted vs paid vs outstanding across all projects; vendor types are DB-backed (no hardcoded enum) with a full CRUD API; isContractor flag drives agreement values, progress bars, and PAID-only enforcement. Search "Nisar Contractor" → PKR 1,400,000 contracted, PKR 780,000 paid, PKR 620,000 outstanding across 2 projects.
  • Document management — receipts in Cloudflare R2; on-demand signed URLs (secure, time-limited); auto-organized by project + vendor; if DB save fails the R2 file is auto-deleted (no orphans). Payment to Nisar on 4th Dec → receipt opens in 5 seconds.
  • Reports hub — 6 types — P&L, Expense Breakdown, Vendor Payment, Project Comparison, Government Audit, and Investment Portfolio; every report exports to both PDF and Excel. Date-range and project filters apply across all types.
  • Investments module — portfolio tracking, valuation history timeline, and ROI calculation per holding. Dashboard total is a placeholder pending integration — individual investment records are fully functional.
  • Profile & settings — name, phone, and avatar managed per user; avatar stored in Cloudflare R2 with a compensating rollback on DB failure; vendor types configurable by OWNER without a code deploy.
