Approach

Most software problems are operations problems.

The Asia Builders ERP started as “the accountant spends 40 hours a month in Excel.” The WhatsNextPlease platform started as “the team doesn’t know who owns what.” The data models followed from those problems — not the other way around.

Read the error logs before Stack Overflow. Know why EXTRACT(DAY FROM date - date) returns an integer instead of an interval — and why that breaks due-date queries at 11 pm on a deadline day.

Design for the failure case: Saga pattern for R2 rollback when a DB save fails. Independent dashboard endpoints so one broken query doesn’t blank the whole screen. Soft deletes so nothing disappears without a trace.

Working code over perfect code — but the working code ships with tests.
